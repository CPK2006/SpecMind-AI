# Design

Design documentation captures the user experience and visual language of the SpecMind AI workspace.

The current frontend includes authentication, a project dashboard, project creation for both workflows, workspace result views, requirement and quality sections, test cases, report content, and Mermaid diagram previews.

Design notes should include the user goal, screen or interaction states, loading and error behavior, accessibility considerations, and responsive behavior. Keep implementation details in `frontend/` and use this section for decisions that should guide future UI work.
