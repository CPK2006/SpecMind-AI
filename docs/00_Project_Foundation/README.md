# Project Foundation

This section defines the purpose, principles, scope, and constraints of SpecMind AI.

SpecMind AI exists to turn ambiguous product ideas and existing software specifications into clear, testable, traceable engineering artifacts. Foundation documents should describe the product's goals, MVP boundaries, terminology, and non-negotiable quality and security expectations.

## Current project context

- Full-stack React/Vite and FastAPI application
- PostgreSQL-backed project and requirement workspaces
- Two primary workflows: pitch-to-SRS and existing-SRS improvement
- AI-assisted generation with local and hosted provider failover

Keep foundation decisions stable and link implementation changes back to the relevant principle or scope decision.
